# 🏡 Hearthly

Hearthly is a full-stack accommodation listing web application inspired by platforms like Airbnb.

Users can browse available listings, search and filter properties, create accounts, add their own listings, upload images, and leave reviews.

## 🚀 Live Demo

https://hearthly-74c6.onrender.com

## 📂 GitHub Repository

https://github.com/OmBombatkar/Hearthly

## ✨ Features

- User registration and login
- User authentication using Passport.js
- Browse accommodation listings
- Search listings by title
- Filter listings by category
- Create new listings
- Edit and delete owned listings
- Upload listing images using Cloudinary
- Add and delete reviews
- Authorization for listing owners and review authors
- Flash messages for user feedback
- Responsive UI using Bootstrap
- MongoDB database for storing users, listings and reviews
